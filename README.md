# LA VOZ BRAVÍA

Página web creada como proyecto de grado 11 para ofrecer servicios de música llanera en vivo, facilitar la contratación de una artista emergente y dar a conocer su trayectoria musical.

## Problemática

Existe dificultad para encontrar servicios de música llanera en vivo que sean accesibles y de calidad para diferentes tipos de eventos.

Este proyecto busca ayudar a:

- Personas que buscan música en vivo para sus eventos.
- Clientes que necesitan un servicio musical personalizado.
- Una artista emergente que busca mayor visibilidad y nuevas oportunidades laborales.
